FAQ

Questions, answered

Which Minecraft versions do the builds work with?

All builds are made in Java Edition 1.20 and tested back to 1.16. Bedrock world files are included for builds marked "Bedrock ready".

What file formats do I get?

A .schem file for WorldEdit or FAWE, plus a full world save so you can open the build in single-player and look around before placing it.

Can I use a build on a public or paid server?

Yes. Every purchase includes a commercial licence. The only thing you can't do is resell or redistribute the files themselves.

Do you do custom builds?

Yes. Send a short description, a rough size, and your deadline using the form below. You'll get a quote within 48 hours.

What if I need help installing it?

Every download comes with a step-by-step install guide. If you still get stuck, reply to your order email and I'll help you personally.
